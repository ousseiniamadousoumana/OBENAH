SSEINY'S V4 — PACKAGE DU SITE

Contenu :
- index.html : page d'accueil principale
- images/sseinys-logo.png : logo SSEINY'S extrait du visuel fourni
- images/cameleon-sseiny.png : caméléon détouré utilisé dans le hero et l'animation du pied de page

Installation : téléverser index.html à la racine du dépôt GitHub et téléverser le dossier images à la même racine. Conserver les chemins relatifs.

Les boutons sociaux utilisent les liens déjà présents dans le projet. Les badges sont des emblèmes décoratifs de marque et ne constituent pas une certification officielle de Facebook ou d'une autre plateforme.
